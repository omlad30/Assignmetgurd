1. Executive Summary

AssignGuard is an event-driven, AI-powered academic integrity and learning management platform built using Node.js, Express, MongoDB Atlas, Cloudinary, Socket.io, and Google Gemini.

Rather than relying on superficial string comparisons or opaque third-party black boxes, AssignGuard implements an in-house Natural Language Processing (NLP) pipeline that vectorizes document text using Term Frequency-Inverse Document Frequency (TF-IDF) and computes multi-dimensional Cosine Similarity against peer submissions in the same assignment cohort. Submissions exceeding a calibrated 65% similarity threshold are automatically placed in a quarantine state.

3. Anti-Evasion Sanitization Layer

The "Secret Weapon": Students often use subtle technical tricks to fool standard plagiarism checkers. AssignGuard implements a multi-layer defense in backend/utils/extractText.js.

A. Zero-Width Token Breaking Attack

The Exploit: Inserting invisible zero-width unicode characters (like \u200B Zero-Width Space, \u200C Non-Joiner, \uFEFF Byte Order Mark) between letters (e.g., c[ZWSP]o[ZWSP]p[ZWSP]y). Human readers see "copy", but a standard tokenizer sees single disconnected letters.

// Purge zero-width invisible characters
sanitized = text.replace(/[\u200B-\u200D\uFEFF\u200E\u200F\u202A-\u202E]/g, '');

B. The Cyrillic Homoglyph Attack

The Exploit: Swapping standard Latin characters with visually identical Cyrillic alphabet letters (e.g., Cyrillic 'а' \u0430 instead of Latin 'a' \u0061).

const homoglyphs = {
  '\u0430': 'a', '\u0441': 'c', '\u0435': 'e', '\u043E': 'o', '\u0440': 'p', '\u0445': 'x', '\u0443': 'y',
  '\u0410': 'A', '\u0421': 'C', '\u0415': 'E', '\u041E': 'O', '\u0420': 'P', '\u0425': 'X', '\u0423': 'Y'
};
sanitized = sanitized.replace(/[\u0430\u0441...]/g, match => homoglyphs[match] || match);

4. The Plagiarism Detection Mathematics

Step 1: TF-IDF Vectorization

For each term t in document d within cohort D:

  • Term Frequency (TF): Frequency of term t in document d divided by total words in d.
  • Inverse Document Frequency (IDF): Penalizes ubiquitous words ("is", "assignment", "the") and amplifies domain keywords ("semaphore", "deadlock", "polymorphism"):
    IDF(t, D) = ln((1 + |D|) / (1 + |{d ∈ D : t ∈ d}|)) + 1

Step 2: Cosine Similarity Formula

Measures the cosine of the angle between two multi-dimensional term vectors rather than mere word counts:

Cosine Similarity(A, B) = (A · B) / (||A|| × ||B||)
= ∑(A_i × B_i) / ( √∑(A_i²) × √∑(B_i²) )
  • Cosine = 1.0 (100%): Identical document vectors / identical keyword distributions.
  • Cosine = 0.0 (0%): Completely orthogonal vectors (no shared keywords).
  • Empirical 65% Threshold: Organic assignment overlap (sharing question prompts and templates) sits at 20–35%. A 65% cutoff precisely separates legitimate formatting from intentional collusion.

6. Judge Defense Sheet: Tough Questions & Winning Answers

Tough Judge Question Winning Technical Answer
"What if two students submit at the exact same second?" "Our database operations are atomic. MongoDB handles concurrent requests through document-level locking and assigns chronological timestamps. The first one processed becomes the baseline; the second is evaluated against all existing records in that assignment's collection."
"Why 65% as the threshold?" "In academic assignments, students share the same questions, templates, and problem definitions, which creates an organic similarity baseline of 20–35%. 65% ensures legitimate formatting isn't falsely flagged while catching paraphrased copying."
"Is the server blocked when a 10MB PDF is parsed?" "No. The initial route handler acknowledges the upload, saves a 'processing' record, and hands the OCR and similarity calculations to Node.js's setImmediate event loop, keeping the server fully non-blocking."
"How do you prevent false positives in AI detection?" "First, we never auto-reject submissions based solely on AI scores. Second, the check is on-demand, initiated by the teacher only when there is reasonable suspicion. Third, our Gemini prompt mandates explainability: it must cite the exact suspicious sentences and provide a reasoned explanation rather than a black-box percentage."
